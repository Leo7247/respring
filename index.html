How the Payload Works

1. 3D Perspective Blur Cascade: An invisible sandbox iframe is injected with 500 absolute-positioned `div` layers using intense perspective offsets and `-webkit-backdrop-filter: blur(100px)`.

2. WebKit Compositor Exhaustion: The MobileSafari / WebKit GPU rendering loop attempt to compute hardware-accelerated blurs across extreme coordinate ranges, consuming system memory instantly.

3. Allocation Loop: A continuous loop calls `crypto.getRandomValues()` along with `navigator.share()` text buffer overflow to trigger watchdog timeouts in SpringBoard.

Safe & Temporary: Respring only restarts the iOS graphical shell (SpringBoard). It does not alter system files or jailbreak your filesystem.
